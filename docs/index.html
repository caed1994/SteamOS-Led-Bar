How it is built

A screen is not a WS2812: real diodes are considerably brighter and their spill is stronger, fire especially. The two breathing animations really are as dim as they look here, though – which is why there is a button to brighten them. To see any of this on the real strip: steamos-utility-center --simulate rainbow draws whatever RAINBOW_SHOWS currently says, and the shape tester on the control panel's Test tab fires each flash shape once.
